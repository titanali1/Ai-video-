# Deisa — استودیوی خلاقیت هوش مصنوعی

یک نمونه‌ی موبایل‌محور و قابل نصب (PWA) به زبان فارسی و راست‌چین برای طراحی تجربه‌ی اپ اندروید تولید محتوای هوش مصنوعی. نشان Deisa یک قاب ویدیو و دکمه‌ی پخش را با گره‌ها و مسیرهای مدار هوش مصنوعی ترکیب می‌کند. شامل داشبورد، فرم ساخت ویدیوی بلند تا ۶۰ دقیقه از متن یا تصویر، ابزار تولید تصویر، ابزار صدا و گویندگی، کتابخانه‌ی پروژه‌ها و تعامل‌های نمایشی.

## اجرا

```bash
python3 -m http.server 8000 --bind 0.0.0.0
```

سپس `http://localhost:8000` را باز کنید. در مرورگر اندروید می‌توان از گزینه‌ی «افزودن به صفحه‌ی اصلی» برای نصب PWA استفاده کرد.

## ساخت APK اندروید

پروژه‌ی بومی WebView در پوشه‌ی `android/` قرار دارد؛ فایل‌های وب داخل APK به‌صورت محلی سرو می‌شوند و انتخاب تصویر با انتخاب‌گر سیستمی است، بدون مجوز کلی حافظه. تنظیمات ساخت: حداقل Android 5.0 / API 21، `compileSdk 36` و `targetSdk 36` برای Android 16؛ اپ از API اختصاصی 37 استفاده نمی‌کند و برای نصب روی نسخه‌های جدیدتر نیز محدودیت نسخه‌ی سیستم ندارد.

با JDK 17، Gradle 9.6.0، Android SDK Platform 36 و Build Tools 36.0.0:

```bash
cd android
./build-apk.sh
```

برای ساخت variant انتشارِ بدون امضا، `./build-release-apk.sh` را اجرا کنید؛ امضای نهایی به keystore نیاز دارد. فایل فعلی `Deisa.apk` یک release APK امضاشده برای نصب مستقیم است. کلید موقت CI برای انتشار فروشگاهی یا به‌روزرسانی بعدی نگهداری نمی‌شود؛ برای توزیع پایدار باید keystore خصوصی متعلق به صاحب اپ تنظیم شود. اگر نسخه‌ی debug قبلی نصب است، پیش از نصب این APK آن را حذف کنید چون گواهی امضایش متفاوت است.

### نصب در Xiaomi / MIUI / HyperOS

APK را در حافظه‌ی گوشی باز کنید و برای همان برنامه‌ای که فایل را باز می‌کند، اجازه‌ی «Install unknown apps / نصب برنامه‌های ناشناس» را در تنظیمات فعال کنید. اگر اسکن امنیتی MIUI هشدار داد، فقط در صورتی ادامه دهید که فایل را از منبع مورد اعتماد گرفته‌اید. محدودیت‌های نصب ناشناس و سیاست‌های امنیتی Xiaomi از داخل اپ قابل حذف نیستند. این ساخت برای Android 5.0 به بالا هدف‌گذاری شده؛ سازگاری با همه‌ی رام‌ها و دستگاه‌های قدیمی بدون آزمون روی خود دستگاه قابل تضمین نیست.

## وضعیت اتصال هوش مصنوعی

این مخزن رابط کاربری و نمونه‌های تعاملی محلی را ارائه می‌کند؛ تولید واقعی ویدیو، تصویر و صدا هنوز به بک‌اند، API مدل‌ها، صف پردازش، فضای ذخیره‌سازی و مدیریت امن اعتبار نیاز دارد. رابط این موارد را به‌عنوان پیش‌نمایش نمایشی مشخص می‌کند و هیچ کلید API در کلاینت نگهداری نمی‌شود.
